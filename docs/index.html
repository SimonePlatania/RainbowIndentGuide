Rainbow Indent Guide

Eclipse update site. This page is not the plug-in — it is the address you paste into Eclipse.

https://simoneplatania.github.io/RainbowIndentGuide/
  1. In Eclipse: Help > Install New Software…
  2. Add…, paste the address above, give it any name
  3. Tick Rainbow Indent Guide, then Next
  4. Accept the license, Finish, restart when prompted

Eclipse warns about unsigned content: the jar carries no digital signature. Confirm and continue.

Another Indent Guide already installed? Remove it first. This one still contributes the extension ids of the original, so p2 refuses to install the two side by side rather than leave you with duplicate preference pages and two painters drawing over each other.
